# MY-AGENT

An AI Project Builder Agent that turns a natural-language app idea into a working software project.

## Vision

The agent acts like a small autonomous software team:

**Idea → Understand → Plan → Design → Build → Run → Test → Debug → Review → Document**

## Core capabilities

- Understand a user's application idea
- Convert the idea into structured requirements
- Break requirements into development tasks
- Create an implementation plan
- Generate and modify project files
- Run the generated project
- Detect errors and failing tests
- Investigate and fix problems autonomously
- Track project progress and decisions
- Generate final README/documentation

## First milestone

Build the planning brain first:

> User enters an idea → agent understands it → agent returns a structured project specification and ordered development plan.

The next milestones will add project generation, execution, testing, debugging, and documentation.
